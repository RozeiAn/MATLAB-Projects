# RedShift (1st Project):
Uses wavelength in differing stars that use the distance from that star to earth (such as star HD 94028) to calculate speed.
This is done using hydrogen-alpha lines evaluated from the significant dip in light intensity to curate a redshift factor.
The redshift factor is then used to calculate the speed in km/s relative to the Earth.
