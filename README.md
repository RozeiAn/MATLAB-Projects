# MATLAB-Projects
All MATLAB Projects for designated projects and solely MATLAB-based projects.

# RedShift (1st Project):
Uses wavelength in differing stars that use the distance from that star to earth (such as star HD 94028) to calculate speed.
This is done using hydrogen-alpha lines evaluated from the significant dip in light intensity to curate a redshift factor.
The redshift factor is then used to calculate the speed in km/s relative to the Earth.

# FEA Direct Stiffness Method:
Uses multiple examples of springs and the notorious hooks law equation to equate aspects of FEA (displacements, reactions, forces).
Methodology to compute 1D and 2D FEA spring-based systems and can be further advanced to incorporate other systems such as potential energy.
